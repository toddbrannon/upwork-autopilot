# Upwork Autopilot

Watches Upwork for jobs that match your rules, scores them with Claude Haiku, drafts proposals with
Claude Sonnet from your knowledge base, and posts them to Slack with Approve / Edit / Skip.
You paste and submit on Upwork yourself — that step is deliberately never automated.

## Setup (once)

1. **Deploy**: Render → New → Blueprint → this repo. Creates a $7 Starter web service + 1 GB disk.
2. **Secrets** (Render → service → Environment), paste values:
   - `ANTHROPIC_API_KEY` — console.anthropic.com → API keys
   - `SLACK_BOT_TOKEN`, `SLACK_SIGNING_SECRET` — create the app from `slack-manifest.yml`
     (api.slack.com/apps → Create New App → From an app manifest), install it to your workspace
   - `SLACK_CHANNEL_ID` — make a channel (e.g. #upwork-jobs), `/invite @Upwork Autopilot`,
     copy the ID from the channel's details panel
   - `DASHBOARD_PASSWORD` — anything long; username is ignored
   - `PUBLIC_BASE_URL` — e.g. `https://upwork-autopilot.onrender.com`
   - `UPWORK_CLIENT_ID`, `UPWORK_CLIENT_SECRET` — after Upwork approves your API key.
     Set the key's callback URL to `PUBLIC_BASE_URL/oauth/upwork/callback`.
3. **Connect Upwork**: open the dashboard → "Connect Upwork" → approve on Upwork.
4. **Knowledge base & rules**: edit from the dashboard. Changes apply to the next job.

## Fallback feed (if Upwork denies the API key)

Any alert service that can POST JSON can feed `POST /ingest/<INGEST_WEBHOOK_SECRET>`
(the secret is generated by Render; see Environment). Body: one job object or a list.

## Slack command

`/autopilot status` · `digest` · `threshold 75` · `pause` · `resume`

## Data rule

Upwork job text is deleted after 24 hours (Upwork API terms). Scores, drafts, decisions and outcomes are kept.

## Local run

```
pip install -r requirements.txt
DATA_DIR=./data DASHBOARD_PASSWORD=dev uvicorn app.main:app --reload
python -m tests.smoke
python -m tests.slack_flow
```

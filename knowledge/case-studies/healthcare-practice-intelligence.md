# Healthcare Practice Intelligence Platform

- Client type: multi-provider OB/GYN practice
- Problem: manual monthly reporting; standard EHR reports showed what happened, not why
- What I did: built an AI-powered analytics dashboard to replace the manual reporting; integrated the Claude API live
  so it generates severity-rated, dollar-quantified operational findings in real time
- Result: surfaced $187K in annualized revenue opportunity from one provider's case-mix pattern that standard EHR reporting had never flagged
- Proof: live demo at northview-dashboard.replit.app
- Tags: healthcare, practice analytics, dashboard, Claude API, AI insights, revenue cycle, EHR data
